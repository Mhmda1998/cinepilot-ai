# CinePilot AI

> From Screenplay to Production.

CinePilot AI is an AI-powered film production copilot that transforms screenplays into production-ready insights, storyboards, and workflows using Gemini, Google ADK, and Google Cloud.

## Project Vision

CinePilot AI is designed to help filmmakers, screenwriters, and production teams understand and organize complex film projects through an intelligent multi-agent workflow.

## Planned Capabilities

- Screenplay analysis
- Scene and character extraction
- Production planning
- Storyboard generation
- Film project knowledge retrieval (RAG)
- Multimodal video and audio analysis
- AI-powered production tools
- Google Cloud deployment

## Technology

- Gemini
- Google ADK
- Vertex AI
- BigQuery
- Google Cloud
- Python
